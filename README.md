A pure-Python (standard library only) program that draws Mochi, a chubby cream cat hugging a glossy pink heart — huge amber eyes with star sparkles, tiny pink heart nose, pink bow, big paws with pink pads — and writes it to /output/entry.png for make.fun's "Make the cutest picture" bounty.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
